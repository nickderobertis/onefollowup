# onefollowup-cli

The `onefollowup` command, as a prebuilt binary: `npm install -g onefollowup-cli`. npm
installs only the carrier package for your platform (`onefollowup-cli-<platform>-<arch>`),
and this launcher runs it. The package carries the CLI executable alone — there is no
JavaScript API. See https://github.com/nickderobertis/onefollowup for the command surface
and its configuration.
